# FileFlow v0.9.0

FileFlow v0.9.0 is a Windows desktop utility for previewing and applying a deliberately narrow set of safe file-organisation operations.

## Core Features

- Preview-first organisation with exact source and destination paths
- Same-volume file moves
- No overwrite
- Deterministic built-in organisation rules
- Persisted History
- Identity-checked safe Undo to the original path
- Recovery protection when an operation cannot be conclusively verified
- VaultSoft desktop interface

## Current Limitations

- Windows only
- Immediate child files only; no folder recursion
- Category destination folders must already exist
- Same-volume moves only
- Maximum 100 real operations per Apply or Undo
- No automatic rename
- No cross-volume support
